# WabiOS

Toy personal "OS" for the Rasperry Pi Pico 2 microcontroller. 

Note: I use the term Operating System pretty loosely here, as I'm writing this in a much higher level language than most operating systems. 

## AI Usage

I like writing my own crappy code, and I won't let AI do it for me. It really robs the joy of making a "personal" OS if it's not actually my design choices and code. I generally use AI as a search engine for documentation, but any AI generated code will be explicitly marked with comments.
